# my-first-agent

An interactive AI stock analysis agent built with Streamlit that processes market data, executes multi-step analysis loops, and presents structured insights through a web UI.

## Tech Stack
- **Frontend/UI:** Streamlit
- **Agent Architecture & Logic:** Python, custom agent execution loops (`app.py`)
- **Data Processing:** pandas, structured prompt handling
